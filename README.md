🌐 Projeto de Infraestrutura de Rede Corporativa - Piaget World

Projeto final desenvolvido para a unidade curricular de **Redes de Computadores II** (CTESP Cibersegurança) no **Instituto Piaget**.

📋 Descrição
O projeto consiste no desenho e implementação de uma rede para uma empresa distribuída por 8 cidades em Portugal. A infraestrutura foi simulada no Cisco Packet Tracer e foca-se em alta conectividade e segurança.

🚀 Destaques Técnicos
Topologia: Estrela com Router Central, garantindo um máximo de 2 hops entre qualquer rede.
Roteamento: Implementação de Rotas Estáticas em toda a infraestrutura.
Segurança: Isolamento lógico da rede de Administração (IP Estático) e proteção WPA2-PSK nas redes Wireless.
Serviços Integrados: DNS:Resolução de nomes centralizada.
Web: Alojamento de site institucional.
E-mail: Domínio corporativo `piagetworld.com`.
FTP & NTP: Gestão de ficheiros e sincronização horária.


🛠️ Como visualizar
1. Descarregue o ficheiro `.pkt` disponível neste repositório.
2. Abra-o utilizando o **Cisco Packet Tracer (v8.0 ou superior)**.
